# Login App

Projeto desenvolvido como atividade avaliativa de Git e GitHub, utilizando o fluxo de branches (main, develop, feature, hotfix, release).

## Funcionalidades

- Tela de login com validação de campos (usuário e senha)
- Tela de dashboard exibida após login bem-sucedido
- Tela de cadastro de novo usuário
- Tema escuro (dark mode)

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- `index.html` — página de login
- `dashboard.html` — painel principal após login
- `cadastro.html` — formulário de cadastro de usuário
- `style.css` — estilização das páginas
- `script.js` — validação do formulário de login

## Fluxo de branches utilizado

- `main` — versão estável e publicada
- `develop` — desenvolvimento ativo
- `feature/*` — novas funcionalidades (dashboard, cadastro)
- `hotfix/*` — correções urgentes (erro de HTML)
- `release/*` — preparação de versão para publicação
